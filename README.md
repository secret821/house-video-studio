# 房源视频工作室

Next.js App Router＋React＋TypeScript＋Remotion 本地房源视频工具。人物开场直接上传录好的视频并保留原声，不需要生成人物或开场配音。照片模式支持开场视频＋房源照片、逐张字幕与解说、可选本机或百炼配音及本地增量导出；免费实拍剪辑支持真人开场＋房屋视频、逐段字幕、原声与音乐混音以及成片/封面导出。

上传照片或视频后，可以主动点击百炼画面文案生成建议。照片分析当前一张图片；视频在本机按各段时间抽两张关键帧，再结合填写的房源信息生成标题和字幕。结果先预览，点击“采纳以上文案”后写入，仍可编辑；不会自动生成配音或改动剪辑时间。关键帧说明不等于完整视频识别，也不是原声逐字字幕。

## 百炼画面文案

1. 沿用 `.env.cloud` 的北京地域Key及业务空间ID，固定调用 `qwen3.7-flash`。服务端配置完成不代表模型权限和余额已经验证。
2. 在百炼控制台确认此模型还有有效免费额度，并开启该模型的“免费额度用完即停”；再在网页勾选确认。程序无法读取免费余额或远程设置该开关，未开启可能按量扣费，不承诺永久免费。
3. 照片模式在当前图片的“按画面生成文案”操作；实拍页在逐段配置区域生成全部片段建议。只有点击生成才会将房源图片/视频关键帧及已填房源事实发给阿里百炼，不会向百炼发送人物开场、音轨或联系人；Key仅在服务端使用。
4. 核对标题、解说/字幕和画面依据，点击采纳。仅采纳照片文案会保留旧配音；解说改变后仍须明确更新或移除旧配音才能导出。视频采纳只改标题和画面字幕，原声、音乐、片段时间不变。
5. 同一事实和素材优先复用已通过校验的本地缓存；更改图片字节、房源信息、片段范围或模板会失效。生成失败可见，不自动重试或切换到其他模型。缓存位于 `data/copy-cache`，不修改旧云端30元测试预算记录。

## 背景音乐来源

实拍页“原创轻钢琴 · Warm Interior”来自 `server/video-edit-music.ts` 的本机数学振荡器、衰减泛音和回声合成，64秒立体声；没有下载歌曲或引用外部录音采样，不调用百炼。它是钢琴风格的程序合成音轨，不是真人钢琴录音。演示房源的16秒氛围音乐由 `scripts/prepare-demo.ts` 在本机合成。两页都可上传自己的音乐；上传音乐的来源由用户自行确认。

## 免费实拍剪辑（本轮推荐）

打开 `http://127.0.0.1:4317/video-edit`，或在照片模式点击“免费实拍剪辑”。本地剪辑和导出无需Key，素材处理留在本机；可选百炼画面文案会发送房屋关键帧到云端，需要Key及免费额度确认。实拍草稿与照片草稿独立。

1. 分别上传真人开场与房屋实拍，支持MP4/MOV、250MB内、最长10分钟。视频会在本地核对真实时长、方向和音轨，并规范帧率与原声音量；原文件不修改。中文文件名在上传边界归一化。
2. 房源信息可逐项编辑，也可在“粘贴整段文案，提取房源信息”中粘贴发布正文、口播脚本及多个版本；点击本地提取，核对后一次填入。支持明确小区名、楼层、面积、户型、装修、标明总价的价格及常见附加空间；重复信息去重，不同值显示候选并阻止直接采纳。规则有覆盖范围，未识别项需补充；不会把黄金楼层、保养很新、拎包入住、手机号或口播全文自动写入视频。只更新采纳字段、封面和片尾，不改原声或逐段字幕。原文和提取预览仅保留在当前页面，采纳字段需保存草稿。编辑逐段字幕时，起止时间对应房屋原视频；每段至少2秒。自动分段只提供中性占位文案，不是AI识别房间。可裁掉走廊或快速转镜，也可覆盖完整原片。
3. 默认保留开场和房屋原声讲解（各100%），原创轻钢琴以8%音量全程铺底、首尾淡化。可以上传自己的音乐并分别调音量。房屋原声开启时只淡化画面，前后人声不重叠；裁切会同时裁掉对应声音，保留完整讲解时各段应连续覆盖原片。画面文案不自动生成配音。
4. 点击“免费导出成片与封面”。相同项目、素材和模板会复用已完成结果，缓存损坏会重新本地构建；当前新视频模式是整片缓存，照片模式仍保留原来的分段缓存。照片/口播与免费剪辑任务不能同时渲染。
5. 主封面采用无蒙层实拍背景与描边艺术字，房源信息与片尾共用。可在“房源信息与文案”的“封面展示时长 / 秒”中设置0.5～10秒，默认1.2秒；保存草稿后保留设置，预览和导出同步，原视频完整顺延。页面播放器也使用该封面。下载MP4与实拍封面，草稿在 `data/video-edit/draft.json`，任务在同目录的jobs；刷新可恢复，服务重启后的中断任务明确标为失败，不冒充完成。源素材在data/uploads，输出在data/exports。

本会话当前原声版：`data/exports/anfu-qianshuiwan-original-audio.mp4`（51.0秒，含1.2秒主封面与两段完整原声）；默认别名 `data/exports/anfu-qianshuiwan-free.mp4` 与封面 `anfu-qianshuiwan-cover.png`；配套正文、重录参考、封面大字和置顶评论在 `data/video-edit/publish-copy.txt`，不含手机号。输出画布1080×1920，源视频实际540×960，输出规格不代表原生高清。内置音乐是数学合成的独立音轨，没有下载歌曲或引用他人录音；Remotion软件许可仍以文末官方许可链接为准。

当前艺术字封面交付：`data/exports/anfu-qianshuiwan-art-cover.mp4` 与 `anfu-qianshuiwan-art-cover.png`，默认1.2秒封面、51.0秒成片。

## 启动与配置

需要 Node.js 22+、pnpm 10+、Google Chrome。项目已有依赖，无需安装本地数字人模型。

```bash
pnpm install
pnpm dev
```

打开 http://127.0.0.1:4317 。生产模式执行 `pnpm build` 后 `pnpm start`（仍启动 Express＋Next 同源服务，请勿直接运行 `next start`）。Next 开发输出 `.next-dev/`，生产输出 `.next/`，不再使用 Vite 或 dist。端口可通过 `PORT` 更换，Chrome 路径可用 `CHROME_PATH` 指定。

项目根目录已经准备私有 `.env.cloud`，填写：

```dotenv
DASHSCOPE_API_KEY=你的北京地域Key
DASHSCOPE_WORKSPACE_ID=你的业务空间ID
```

请使用华北2（北京）Key。业务空间ID在百炼控制台的业务空间管理中查看；万相API需要此ID，配音单独可只填Key。配置由Node每次调用时读取，**保存配置并刷新网页即可**。不要使用`VITE_`前缀，密钥不会进入前端包或Git。新环境可复制`.env.cloud.example`，不要覆盖已填的配置。

```bash
pnpm cloud status
```

此命令只检查配置格式和本地预算，零网络请求；`ready:true`不代表账号权限、余额或模型已开通。真实鉴权及服务权限在首次生成时验证。

## 网页操作

1. 在照片模式的“上传开场视频”选择已经录好的 MP4/MOV，单个不超过250MB、最长60秒。视频在本机核对时长、方向及音轨并规范编码，上传成功后自动保存；更换失败保留旧开场。开场可选，移除后可直接从房源照片开始。
2. 播放开场预览，确认原声与画幅；画面按当前成片画幅居中裁切。上传视频不叠加AI标识、不根据旧台词生成字幕、不生成或克隆声音。文件没有音轨时不会凭空补配音。
3. 开场上传、更换和导出都在本机完成，不需要云端Key、不消耗人物生成测试额度。已有生成开场仍可读取、预览和复用，但页面已移除人物照片、开场台词、录音及人物生成入口；旧云端脚本仅供历史流程恢复，不是当前操作步骤。
4. 添加房屋照片，点选任意照片，在列表下方“第X张 · 文案配置”填写标题、解说和独立字幕。字幕留空跟随解说；只改字幕保留声音且不调用模型。改解说后旧音频保留供试听，但标记过期并阻止导出，需明确选择仅此张百炼配音（按字计费）、本机配音（免费、音色基础）、上传录音或移除旧配音。批量“补齐缺失 / 已改词配音”跳过已有匹配音频。开场配音文字与台词不一致时服务端要求重新生成。
5. 点击“更新当前片段并合成（免费）”或“导出MP4”，本地更新变化片段，再拼接完整成片。不会自动生成配音或人物口播；结果显示本地更新/复用的分段数量。首次需要建立缓存，已交付旧MP4不会被伪装成分段缓存。

房源照片的百炼配音需要Key，按钮旁显示配置状态；本机配音与上传录音不需要模型费用。开场视频上传和本地导出不需要Key。字幕按句估时，不承诺逐字强制对齐。

## 单张修改与资源复用

- 只改标题、字幕、运镜：免费本地更新，人物视频和已有配音复用。
- 改解说并同步换声音：可选择本机免费配音或自行录音；选择百炼时只有这一张的新文字参与计费，人物开场不重新生成。同一云端文字请求有持久缓存。
- 导出将片头、照片主体及相邻淡化转场分别缓存在 `data/render-cache`。一张中间照片修改会更新本段及两个相邻转场；直接切换仅更新本段。重试复用已完成缓存，未完成/损坏的缓存不冒充成功。
- 更改全局房源信息、画幅、模板等会更新相关画面。有背景音乐且改动导致后续时间位置变化时，后续音乐位置需重算。此类仍是本地计算，没有模型费用。
- 视频分段保持H.264，音频以48k PCM连续拼接后只编码一次AAC；整片画面采用流复制，不重压缩全部画面。缓存键包含素材字节、模板版本和相关场景输入；旧草稿新增的独立字幕默认跟随解说。
- 不自动删除缓存或旧成片；它们占用本机磁盘，清理 `data/render-cache` 后下次会重新建立缓存，源照片和云端预算不能一起删除。

## 历史云端生成脚本（当前网页不再使用人物生成）

已准备`data/house-tour-v2/project-bailian.json`，包含用户的8张真实照片、原人物照和经复核的聊天式文案；旧项目另存保留。可在网页“导入配置”使用，也可在运行本地服务后执行：

```bash
pnpm cloud voices           # Cherry与Serena两种配音试听，不生成人物视频
```

也可一次运行 `pnpm cloud all Cherry`，自动串联开场、全部配音和导出。推荐先试听后使用`opening`和`finish`。CLI的`finish/all`会备份旧草稿，将新项目保存为网页当前草稿。完成后文件在`data/exports/house-tour-cloud-v2.mp4`。

## 费用与失败恢复

当前测试固定**最多30元、两版人物开场、每版12秒**，包含网页和CLI共用的预算记录。万相720P公开价0.9元/秒，每版预留10.8元；Qwen3-TTS-Flash语音公开价0.8元/万字符，检测另计。客户端预算是按公开价保守预留，**不是实际账单或平台硬扣费限制**，优惠、免费额度与实际扣费以百炼为准。公开价核对于2026-10-25。

所有付费POST先写预算，同一输入按照片/音频内容与模型身份缓存。重复点击或重跑会复用结果/查询原task_id；服务重启后同输入再次点生成可恢复。付费POST超时或失败保留记录，不自动重复提交，需先核对百炼任务与账单。不要删除预算文件来“重试”，否则会丢失防重依据。已知task_id或已成功的远程地址会用于继续查询/下载；结果URL有时效，过期需人工核对。未知提交与失败检测不会自动重提。

本地生成命令共享进程锁。进程退出后可识别失效锁；锁文件损坏时先核对原进程与任务，不能盲删。渲染失败与云任务失败分别显示，已生成的配音和口播不会因为导出失败而再次付费生成。真实人物自然度、音色和嘴型需填Key后通过样片验收；本轮已完成真实百炼配音及万相口播联调；自然度以实际样片和用户试听为准。

## 文件与验证

- `src/features/studio`聚合编辑器、请求及状态；共享Zod契约在`src/services/definition`，视频模板在`src/video`。
- `server/cloud.ts`负责官方协议与素材边界，`cloud-budget.ts`负责持久预算，`cloud-opening.ts`负责网页任务。
- `.env.cloud`仅服务端私有读取，`.env.cloud.example`为可提交模板；`data/`忽略提交。
- `data/uploads`是照片/音频/开场MP4，`data/exports`是成片，`data/cloud-opening-jobs`是网页任务，`data/house-tour-v2/cloud/budget.json`是预算与云任务恢复依据。
- “保存草稿”写`data/draft.json`；导出配置不嵌入素材，迁移时需一并复制`data/uploads`和`public/demo`。

```bash
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
pnpm verify
```

`pnpm test`完全离线：隔离文件系统、模拟云HTTP，覆盖预算、防重、失败、恢复、下载边界与真实FFmpeg编码，不调用付费服务。`pnpm verify`使用macOS本机语音验证实际本地API到MP4，不调用云配音，也不覆盖用户草稿；`VERIFY_JOB`可检查已有网页导出。仅本机监听，单机使用，不包含公网多用户部署。修改模板后重启服务刷新内存中的渲染包；磁盘分段缓存按模板内容自动失效。
