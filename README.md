## 临时资源与磁盘维护

`pnpm storage:maintenance` 默认只输出独立验收目录的JSON盘点。管理员确认某个验收目录已完成、以后不再作为运行目录后，执行 `pnpm storage:maintenance --complete artifacts/验收目录名` 标记；标记或目录最后修改满7天后，`pnpm storage:maintenance --apply` 才会删除。`--days` 可延长保留期，不能少于7天。历史上传、成片和缓存不自动加入此删除范围；模型、依赖、登录配置及发布包始终排除。服务端每日维护安装与回滚见 [部署说明](deploy/README.md#磁盘维护)。

## 智能画面清理（本地免费）

在「01 素材」上传房屋视频后，点击「智能清理并应用」。程序检测人脸、明显身体（含镜中人）和持续过暗画面，用检测合格的房屋视频区间补齐；优先使用同片画面，短区间可能重复。人物口播开场不参与处理，原片不修改，完整原声、总时长、已有字幕与剪辑时间保留。成功后自动应用并保存当前浏览器草稿，点击「撤回画面清理」可在当前页面恢复素材引用，之后重新生成成片。

管理员首次运行 `pnpm setup:smart-clean`，从官方 ONNX 模型库下载并校验 SHA256，真实推理自检通过后启用。公共依赖 `onnxruntime-node` 固定为 1.31.1，模型默认在 `.runtime/smart-clean`，可由管理员设置 `STUDIO_SMART_CLEAN_DIR`。安装需要联网，检测与编码在本机完成，不调用云端识别或收费接口。任务、抽帧、清理副本按账号 workspace 隔离，共用媒体单槽，进入处理后最多30分钟，可取消；失败保留原素材。没有合格补画面时停止，请补充无人且明亮的房屋视频。

1. 沿用 `.env.cloud` 的北京地域Key及业务空间ID，固定调用 `qwen3.7-flash`。服务端配置完成不代表模型权限和余额已经验证。

4. 可填写“文案要求”指定语气和重点，房源数字仍需先填入已确认字段。长片段目标45～90字、分2～3句，信息不足时不凑字数；短片段字幕按阅读长度保留完整开头短句。视频另展示完整说明参考，不写入成片或替换原声。原稿出现未提供的装修、产权、朝向、车位等已配置标签时会警告；标题/字幕（照片另含解说）仍含这些标签时禁用采纳，需先删改。该检查不能覆盖全部事实，仍需核对画面。未提供的阿拉伯数字、错乱镜头或截断输出会拦截。

6. 同一事实、要求和素材优先复用缓存；图片字节、房源信息、片段范围、提示规则或模板变化会失效。失败可见，不自动重试或切换模型。缓存位于 `data/copy-cache`，不修改旧云端30元测试预算记录。

房源详情截图可在同一区域主动上传识别，支持JPG/PNG/WebP、单张最多10MiB。管理员先用Python 3.10～3.13运行 `pnpm setup:ocr`；默认目录`.runtime/ocr`，可用`STUDIO_OCR_DIR`指定持久目录，或用`OCR_BOOTSTRAP_PYTHON`指定安装解释器。安装会把RapidOCR 3.9.2、ONNX Runtime CPU和公开中文轻量模型放入独立虚拟环境，通过中文截图离线自检后才开放按钮；识别请求不下载模型、不调用云API。贝壳式详情截图优先保留户型图下的房源卡片和概览，按坐标把售价、房型、建筑面积与上方数字对应，避免把户型图内各房间面积当成整套建筑面积。长截图按段识别，原图处理完即从当前账号临时目录删除，页面成功后也不保留截图预览。OCR文字与待确认字段进入当前草稿；检查`㎡`、`+万`、税费及不同版本后点击“确认并填入房源信息”。截图不作为视频素材，也不会自动生成文案、配音或成片。仓库通用Docker构建仍不会自动安装OCR虚拟环境；2026-11-03线上冻结镜像已单独在Linux内安装并自检，详情见部署记录。Linux无图形环境可在构建时设置`STUDIO_OCR_HEADLESS=1`使用无界面OpenCV；不能复制macOS虚拟环境。其他Linux部署仍须在整服务资源限制下验收OCR内存、长图和媒体任务排队；本机自检不能替代上线验收。

页面顶部可选择“杂志留白”或“经典实拍”，两者都有可放大的封面参考图：第一套展示虚构人物口播首帧，第二套展示房屋，以区分默认封面来源。两套保留相近的大字字号，杂志留白使用橙金色正体衬线字、深色描边与下划线，经典实拍保留白色斜体大字和珊瑚红总价，取消自动缩小字号；杂志片内装饰标题同步橙金衬线风格，原声字幕保持经典可读样式，无文字底色或顶部边框；封面文字左对齐并放在上半部，下方留人物，缺省杂志留白项目取口播开场第0帧；切换模板时同步应用目标封面来源：经典取首份房屋素材，杂志取口播开场，仍可手动更改当前来源。经典保留原描边字和首份房屋素材封面；旧草稿缺少模板字段时保持经典。两者均可手动选择口播、房屋素材或单独上传图。选择随当前草稿保存。生成一版后可切换模板并点击“重新生成成片”，同一套房源即可生成两种样式，无需重新上传或填写；切换会同步更新模板及其封面来源、封面版式、片内文案/片尾样式；素材、房源文字、原声、已编辑字幕、配乐和剪辑时序保留。上一版成片仍显示对应模板的下载入口，MP4/封面文件名也包含模板名；预览弹窗始终使用当前配置实时渲染；上一版成片单独标明实际模板并提供播放/下载，不替代当前预览。两份成片各自保存于账号临时导出目录，仍按原有到期规则清理；草稿只保留当前一套信息，不新增历史草稿。底图冻结且静音，不使用约1秒的缩略图；预览、MP4开头和独立PNG共用模板。选择上传但没有图片时阻止导出。

顶部“新建房源视频”先准备当前账号的默认内置轻钢琴配乐（40%音量），保存新草稿后替换当前编辑内容，旧草稿不再引用的原片会在空闲且不被另一模式引用时回收；临时成片与处理缓存仍按原有到期规则清理。默认配乐可在声音设置更换或关闭；恢复已有草稿时保留原选曲和关闭状态。音乐准备或保存失败保留当前项目；新会话编号隔离旧任务，刷新不会把旧成片当作新项目结果。下拉菜单在所有宽度对齐输入框，空间不足时向上展开。

顶部吸顶显示“新建”“保存草稿”和“更多”，页面下滑后仍可使用；步骤栏、预览和跳转位置自动避让页头实际高度，窄屏换行也不会覆盖。更多菜单显示当前登录账号（以服务端会话返回的登录名为准），每次打开重新读取，保留模式切换和退出登录入口。退出须在弹窗中确认，取消不退出；本机未启用登录时明确说明并禁用退出。底部操作栏固定显示“生成成片（免费）/重新生成成片”；完成后出现“下载MP4”和“下载封面”。生成执行本机制作，符合缓存时可复用；下载只取得最近完成的文件，不重新制作。修改内容后需重新生成才能让下载文件更新。照片精细编辑采用同样的区分。

当前草稿自动保存到服务器的当前账号：文字、原始整段文案、待采纳提取/画面文案、原声字幕编辑稿、配置和已上传素材引用。进入页面先查询，有草稿就回填；同账号换浏览器也可继续。每账号、每种模式只保留当前一份，修改覆盖，新建替换；保存只提交JSON，不上传第二份视频，也不把原片下载回来备份到IndexedDB。页头显示保存中、已保存或失败，可点击“保存草稿”重试；没有收到服务端确认就不会显示成功。旧页面的过时保存会被拒绝，避免覆盖另一页面的新草稿。已上传原片保留到新建或移除，重启不丢；仍在被另一模式引用或有任务/下载使用时等待安全回收。导出成片仍是临时文件，请及时下载。旧浏览器JSON仅在服务器没有草稿时尝试迁移，之前已缺失的原片仍需重新上传；旧IndexedDB数据不在本次迁移中删除。

上传状态处可直接点击“终止上传，重新选择”，终止当前视频与本批剩余上传；取消或失败保留已有素材。房屋素材行可逐份替换，保留顺序与文案，并将片段范围适配新时长，替换完成后才移除旧本地备份。

生成请求返回任务编号、显示“任务已提交，正在后台生成”后，可锁屏、切换应用或关闭页面；任务由本机/服务器服务执行，浏览器草稿备份和进度轮询不控制任务执行。返回前台、联网或重新打开页面会查询原任务，不重复提交。原片上传尚未完成时仍需保持页面打开；本机/服务器服务必须持续运行，服务重启中断任务会如实显示失败，不能把关闭浏览器与关闭服务混为一谈。

实拍页按顶部编号定位：1上传人物开场及多份房屋视频/照片，2粘贴整段文案并核对房源信息，3设置封面及可选音乐，4预览后生成。空白页面就能直接填写文案，无需先上传。AI文案、逐段时间与声音细调在对应的可选折叠区；AI仍须确认免费额度并主动调用，结果只有采纳才写入。更改自动保存到当前草稿，成片更新后再下载。

上传控制接口共用现有工作室登录和来源校验：GET /api/video-edit/get-upload-status 返回 active（空闲为null；进行中含id、name、phase、startedAt和deadline），POST /api/video-edit/cancel-upload 接收当前任务id并等待清理完成；旧任务id不能取消后来开始的任务。启用多账号后业务API须附带登录会话返回的X-Studio-Workspace身份头，服务端与Cookie所属账号核对，不接受靠请求头切换数据归属。POST /api/video-edit/upload-video保留FormData的file字段，可带uploadId查询参数，旧调用仍兼容；接收与信息校验共用15分钟期限。响应新增可选preparation（original/ready），新src为/media/source-UUID.mp4、poster为固定/demo/video-pending.svg；旧import路径继续接受。生成时以服务端原片路径判断是否需要准备，不能靠客户端状态跳过。旧网页须刷新后使用新的原片响应；前后端及视频包同版本发布，无数据库变更。

对应接口仍由同源Express处理：POST /api/copy/extract-property 接收text和freeQuotaConfirmed:true，返回model、cached和含候选/原文依据的fields；POST /api/copy/generate-copy 可带可选brief，返回items和可选warnings。公共Zod契约与前端请求同步，云端接口无新增Key。

本地截图入口使用 `GET /api/copy/get-ocr-capability` 和 `POST /api/copy/recognize-property-screenshot`（multipart字段`file`），只返回有上限的OCR文字；前端沿用同一文本提取与确认流程。截图解码、OCR推理共用媒体单槽和账号存储预算。Python依赖固定于`scripts/ocr-requirements.txt`，在Linux上重新安装，不复制Mac虚拟环境。

## 左上角水印

实拍页在“封面与声音”中、照片页在“运镜、声音与输出设置”中可直接编辑“左上角水印”，默认“青连实拍”，单行最多20字，留空即可关闭。水印为靠左上的淡珊瑚橙色粗斜体衬线艺术字，带浅色细描边与轻微阴影，全片显示，包含开头封面、人物开场、房屋画面与片尾；预览和实际MP4一致，实拍独立封面也一致。修改后保存草稿并重新生成成片，旧草稿缺少该字段时自动使用默认文字。改水印不会修改原声、素材顺序或视频时长。实拍推荐配乐40%、照片模式20%；旧草稿和静音设置保留，分别点击“推荐配乐”可应用新音量，原声讲解音量不变。

## 背景音乐来源

实拍页展开“封面与声音 → 音乐、原声音量与转场”，可选择5首内置配乐：原创轻钢琴、明亮拨弦、轻松律动、舒缓氛围、清透铃音。选择即应用，可在下方试听原曲，刷新后保留选择；调整配乐后须重新生成MP4。原声讲解音量不随换曲改变，默认配乐40%，可分别调整或关闭音乐。

五首均由 `server/video-edit-music.ts` 在启动时用本机数学振荡器、不同节奏/音色和回声合成，每首64秒立体声，成片自动循环并在首尾淡化；没有下载歌曲或引用外部录音采样，不调用百炼。它们是程序合成音轨，不是真人乐器录音。演示房源的16秒氛围音乐仍由 `scripts/prepare-demo.ts` 在本机合成。两页都可上传自己的音乐；上传音乐的来源由用户自行确认。

管理员可执行 `pnpm setup:compositor` 启用纯视频时间线的原生叠加加速。安装固定版本的公开 FFmpeg 发行资产，校验压缩包、二进制与许可证，并执行真实叠加自检；默认安装在 `.runtime/compositor`，可用 `STUDIO_COMPOSITOR_DIR` 指定绝对路径。生产应由管理员持有、应用账号只读。该工具只处理应用生成的原始YUV帧和透明PNG，原片解码、原声及封装仍使用固定Remotion工具，不调用系统FFmpeg或收费服务。缺少或校验失败时保留兼容流程；混合照片/重叠转场继续使用原有渲染路径。1核/768MiB下13.2秒公开样片从121.6秒降到约61.6秒，单次短片数据不代表所有素材；详情见 `artifacts/render-optimization-2026-10-30/verification.md`。

兼容接口 `GET /api/video-edit/get-original-music` 可选查询参数 `track=felt-piano|sunny-pluck|relaxed-lounge|airy-ambient|clear-bells`，省略仍返回原钢琴，非法值返回400。共享定义在 `src/services/definition/music.ts`，响应仍为原AudioAsset，按当前账号复制到媒体目录；草稿结构不变。前后端须同批更新并重启本地服务，旧后端会忽略新选曲参数。

## 默认制作流程

打开 `http://127.0.0.1:4318/video-edit`，或在照片模式点击“免费实拍剪辑”。本地剪辑和导出无需Key，素材处理留在本机；可选百炼画面文案会发送房屋关键帧到云端，需要Key及免费额度确认。实拍草稿与照片草稿独立。

1. 上传真人开场，再批量添加房屋视频或照片，也可拖入对应上传区。数量、格式和大小见上方“默认统一制作入口”。视频在本机核对真实时长、方向和音轨，并规范帧率与原声音量；原文件不修改。中文文件名在上传边界归一化。
2. 房源信息可逐项编辑，也可粘贴发布正文、口播脚本及多个版本；点击本地提取，核对后一次采纳。支持明确小区名、位置、类型、建筑层数、所在楼层、面积、户型、装修、总价及常见附加特点；重复信息去重，冲突先确认。未识别项可手填，不把营销评价、手机号或口播全文自动写入视频。原文和预览只在当前页面保留，采纳字段需保存草稿。逐段字幕独立编辑；视频起止对应各自源片，每段至少2秒，照片按展示时长配置。“按素材重新分段”恢复每份素材的默认章节和占位标题，会重置章节文字；它不识别房间。
3. 默认保留开场和房屋原声讲解（各100%），原创轻钢琴以40%音量全程铺底、首尾淡化。可以上传自己的音乐并分别调音量；旧草稿保留已设音量，可点“推荐配乐（40%）”调整。房屋原声开启时只淡化画面，前后人声不重叠；裁切会同时裁掉对应声音，保留完整讲解时各段应连续覆盖原片。画面文案不自动生成配音。
4. 点击“免费导出成片与封面”。相同项目、素材和模板会复用已完成结果，缓存损坏会重新本地构建；当前新视频模式是整片缓存，照片模式仍保留原来的分段缓存。照片/口播与免费剪辑任务不能同时渲染。
5. 在“封面底图与时长”选择底图并设置展示秒数，来源和限制见上方说明。主封面采用真实背景与描边艺术字，房源信息与片尾共用。保存草稿后设置保留，预览、MP4开头和独立封面同步。下载MP4与封面；草稿在 `data/video-edit/draft.json`，任务在同目录jobs。刷新可恢复，服务重启后的中断任务明确标为失败。源素材在data/uploads，输出在data/exports。

本会话当前原声版：`data/exports/anfu-qianshuiwan-original-audio.mp4`（51.0秒，含1.2秒主封面与两段完整原声）；默认别名 `data/exports/anfu-qianshuiwan-free.mp4` 与封面 `anfu-qianshuiwan-cover.png`；配套正文、重录参考、封面大字和置顶评论在 `data/video-edit/publish-copy.txt`，不含手机号。输出画布1080×1920，源视频实际540×960，输出规格不代表原生高清。保留原声、无画面重叠的纯视频时间线采用稀疏字幕动画图层＋流式原生合成；照片混合或重叠转场沿用完整浏览器渲染。两条路径使用相同模板、帧时序和音量，最终H.264/30fps/CRF19、AAC48k，不降低输出分辨率。内置音乐是数学合成的独立音轨，没有下载歌曲或引用他人录音；Remotion软件许可仍以文末官方许可链接为准。

当前艺术字封面交付：`data/exports/anfu-qianshuiwan-art-cover.mp4` 与 `anfu-qianshuiwan-art-cover.png`，默认1.2秒封面、51.0秒成片。

## 启动与配置

需要 Node.js 22+、pnpm 10+、Google Chrome。项目已有依赖，无需安装本地数字人模型。

```bash
pnpm install
pnpm dev
```

打开 http://127.0.0.1:4318 。生产模式执行 `pnpm build` 后 `pnpm start`（仍启动 Express＋Next 同源服务，请勿直接运行 `next start`）。Next 开发输出 `.next-dev/`，生产输出 `.next/`，不再使用 Vite 或 dist。端口可通过 `PORT` 更换，Chrome 路径可用 `CHROME_PATH` 指定。云端历史脚本与本地服务使用相同的 `PORT`；验收脚本默认访问4318，自定端口时设置 `VERIFY_ORIGIN`。

本地启动遇到 `EADDRINUSE` 时，会先核对端口占用者是否为同一用户、同一项目目录启动的旧工作室进程；确认后停止旧进程，等待端口释放，再重试一次。不能确认占用者、端口未释放或公网模式启动时会明确报错，不会结束其他服务。需要手动排查可运行 `lsof -nP -iTCP:4318 -sTCP:LISTEN`；重新启动会中断旧进程正在执行的任务。

## 照片精细编辑（/photo-mode）

1. 在照片模式的“上传开场视频”选择已经录好的 MP4/MOV，单个不超过1GB、最长60秒。视频在本机核对时长、方向及音轨并规范编码，上传成功后自动保存；更换失败保留旧开场。开场可选，移除后可直接从房源照片开始。
2. 播放开场预览，确认原声与画幅；画面按当前成片画幅居中裁切。上传视频不叠加AI标识、不根据旧台词生成字幕、不生成或克隆声音。文件没有音轨时不会凭空补配音。
3. 开场上传、更换和导出都在本机完成，不需要云端Key、不消耗人物生成测试额度。已有生成开场仍可读取、预览和复用，但页面已移除人物照片、开场台词、录音及人物生成入口；旧云端脚本仅供历史流程恢复，不是当前操作步骤。
4. 添加房屋照片，点选任意照片，在列表下方“第X张 · 文案配置”填写标题、解说和独立字幕。字幕留空跟随解说；只改字幕保留声音且不调用模型。改解说后旧音频保留供试听，但标记过期并阻止导出，需明确选择仅此张 Kokoro 配音（免费）、上传录音或移除旧配音。批量“补齐缺失 / 已改词配音”跳过已有匹配音频。开场配音文字与台词不一致时服务端要求重新生成。
5. 点击“更新当前片段并合成（免费）”或“导出MP4”，本地更新变化片段，再拼接完整成片。不会自动生成配音或人物口播；结果显示本地更新/复用的分段数量。首次需要建立缓存，已交付旧MP4不会被伪装成分段缓存。

房源照片的单张和批量配音使用本地 Kokoro-82M v1.1-zh，无需Key或模型费用；须先完成下方安装，按钮旁显示真实安装状态。开场视频上传和本地导出不需要Key。字幕按句估时，不承诺逐字强制对齐。

## 本地 Kokoro 中文配音

照片模式的单张与批量配音统一使用官方 `hexgrad/Kokoro-82M-v1.1-zh`，默认 `zf_001` 中文女声，24kHz PCM WAV。长文案按标点和音素长度拆分后完整拼接。已匹配的配音保留，需要替换旧声音时点击单张生成；真人开场与实拍讲解保留原声。

先准备 Python 3.10～3.13，再执行 `pnpm setup:kokoro`。默认使用 `python3`，可用 `KOKORO_BOOTSTRAP_PYTHON` 指定解释器。首次安装下载公开依赖、英文读音词典与官方模型，核对 SHA256，并在离线中文合成及解码成功后才启用按钮。后续推理不上传文字，不调用付费接口。`scripts/kokoro-inference.py` 仅适配官方 Python 推理库，业务编排仍在 TypeScript。

运行环境默认 `.runtime/kokoro`（Git忽略），管理员可用 `STUDIO_KOKORO_DIR` 指定独立绝对路径。模型和依赖持久保存；业务文字临时文件及生成音频仍在账号工作区，文字在结束/失败后删除，音频按既有临时媒体规则清理。推理复用重型媒体单槽，每次进程退出释放模型内存，单次最长5分钟，失败保留页面旧配音。

Linux安装使用CPU版PyTorch；不能复制macOS虚拟环境。现有生产服务768MiB限制尚未完成模型资源验收，本轮没有发布；须先在独立候选验证。旧百炼历史CLI与预算仅供兼容，不参与照片页配音。官方用法见 [Kokoro v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)。

## 单张修改与资源复用

- 只改标题、字幕、运镜：免费本地更新，人物视频和已有配音复用。
- 改解说并同步换声音：可选择本地 Kokoro 免费配音或自行录音；只有主动点击生成的文字参与推理，人物开场不重新生成。
- 导出将片头、照片主体及相邻淡化转场分别缓存在 `data/render-cache`。一张中间照片修改会更新本段及两个相邻转场；直接切换仅更新本段。重试复用已完成缓存，未完成/损坏的缓存不冒充成功。
- 更改全局房源信息、画幅、模板等会更新相关画面。有背景音乐且改动导致后续时间位置变化时，后续音乐位置需重算。此类仍是本地计算，没有模型费用。
- 视频分段保持H.264，音频以48k PCM连续拼接后只编码一次AAC；整片画面采用流复制，不重压缩全部画面。缓存键包含素材字节、模板版本和相关场景输入；旧草稿新增的独立字幕默认跟随解说。
- 不自动删除缓存或旧成片；它们占用本机磁盘，清理 `data/render-cache` 后下次会重新建立缓存，源照片和云端预算不能一起删除。

## 费用与失败恢复

当前测试固定**最多30元、两版人物开场、每版12秒**，包含网页和CLI共用的预算记录。万相720P公开价0.9元/秒，每版预留10.8元；Qwen3-TTS-Flash语音公开价0.8元/万字符，检测另计。客户端预算是按公开价保守预留，**不是实际账单或平台硬扣费限制**，优惠、免费额度与实际扣费以百炼为准。公开价核对于2026-10-25。

所有付费POST先写预算，同一输入按照片/音频内容与模型身份缓存。重复点击或重跑会复用结果/查询原task_id；服务重启后同输入再次点生成可恢复。付费POST超时或失败保留记录，不自动重复提交，需先核对百炼任务与账单。不要删除预算文件来“重试”，否则会丢失防重依据。已知task_id或已成功的远程地址会用于继续查询/下载；结果URL有时效，过期需人工核对。未知提交与失败检测不会自动重提。

本地生成命令共享进程锁。进程退出后可识别失效锁；锁文件损坏时先核对原进程与任务，不能盲删。渲染失败与云任务失败分别显示，已生成的配音和口播不会因为导出失败而再次付费生成。真实人物自然度、音色和嘴型需填Key后通过样片验收；本轮已完成真实百炼配音及万相口播联调；自然度以实际样片和用户试听为准。

### 配乐与生成建议试听/修改

选择“使用原创钢琴”后，成片预览旁会显示曲名和配乐音量；若原音量为0，会恢复默认40%，非零自定音量保留。旧草稿若配乐被人声盖住，可点“推荐配乐（40%）”，只调整配乐，不改原声音量。音乐控件播放的是未混音原曲，混音听感以成片预览为准。点击播放器播放，可用“只听配乐 / 恢复原声与配乐”作对照，此切换只影响当前试听，保存和导出仍使用原声与配乐设置。“最近一次导出”是固定文件，更换文案或配乐后需重新导出。

画面文案生成建议可在采纳前直接修改每段标题、字幕；照片模式还可修改解说。画面依据只读，修改不再次调用模型；点击采纳后才写入项目。采纳后再次编辑可重新采纳，仍不自动配音；修改事实、素材或时间范围会隐藏旧建议。

### 背景音乐：内置兜底与在线搜索

实拍“封面与声音 → 音乐、原声音量与转场”和照片模式背景音乐区域都可选曲。内置五首无需外网；在线可输入钢琴、吉他、氛围等常用中文词（会显示对应的英文标签），或直接输入 piano、acoustic、ambient 等英文词后点击“搜索”；也可点击常用关键词按钮。搜索完成后显示本页曲目数量并自动展开结果；空结果会提示换词，不会自动代选。点每项右侧 播放／暂停按钮 试听／暂停，点曲名选用。搜索失败不会移除已选音乐，内置曲目和本机上传继续可用。

在线来源为 ccMixter，只展示符合 CC BY 的纯音乐；选用后保存到当前账号临时目录，再用于视频生成。请复制曲目下方署名，在发布视频的描述中保留。每首最多20MiB、10分钟；搜索25秒、导入10分钟超时，换曲或重试即可。账号临时文件仍按2小时未使用或服务重启清理。在线试听由服务器按曲目来源页加载到账号临时目录，首次播放受外网影响，暂停加载会取消下载；之后选用复用已完成的文件，生成不依赖外网。

在线曲目首次试听或选用可能需要数分钟。选用时可点弹窗“取消加载”切回内置曲目；试听加载时再次点 播放／暂停按钮 可取消，不会更换当前音乐。

页面统一通过 [Studio common UI](src/features/studio/common/README.md) 使用封装控件。按钮、表单、输入、选择、弹窗、上传、进度等共享样式入口；ESLint阻止业务页面直接导入antd。参考科研工作台CommonButton封装方式，保留本项目手机触控、中文长文案和原生antd事件/ref契约。
