# 免费 Nano 原声字幕

用户确认三份普通话原片的 Nano 转写整体更好。本轮候选使用 Fun-ASR-Nano F16 编码器＋Q8 语言模型、FSMN VAD；Nano 先退出，再顺序运行 SenseVoice INT8 的 CTC 强制对齐。对齐只提供时间，不替换 Nano 文字；采用主动生成、编辑文案、确认添加的流程，默认不添加，与原房源文案/镜头字幕/配音独立；沿用单槽、账号隔离、取消和两小时临时媒体规则。

## 安装及构建

只面向新腾讯云 Linux x86_64 的 3 CPU / 2560MiB 整服务验收，不能部署到旧 768MiB 服务。普通 Linux 管理员先安装 `python3-venv cmake g++ make`，然后运行 `STUDIO_ASR_ENGINE=nano STUDIO_ASR_DIR=/独立运行时路径 pnpm setup:asr`。安装脚本按 SHA256 校验公开模型、源代码，编译 Debian 兼容运行时，并执行真实中文离线自检后写就绪标记。旧引擎仍是默认值，不能只手工改 ready.txt。

官方 Linux v0.2.6 二进制依赖 GLIBC 2.38，生产容器为 2.36，因此固定源码本地编译。审阅补丁将编码器和语言模型设为 3 线程、微批 256、保留上下文 2048；解码出错或达到词数上限直接失败，不能把截断文本当成功。Mac 上的初步效果测试不替代此 Linux 构建及整服务验证。

冻结部署使用 `Dockerfile.asr-nano`，传入已核验的 `STUDIO_BASE_IMAGE`。准备独立白名单上下文：从当前生产镜像导出 server/subtitles.ts，只应用本轮引擎选择/缓存标识变更；加入本轮六个安装/推理文件，六份固定摘要公共模型和两份固定摘要公开源代码压缩包。路径见同名 dockerignore。禁止直接打包本机 `.runtime`、识别对照、原片、日志、账号、环境变量或整个脏工作区。构建阶段安装编译器，最终镜像仅复制新推理运行时和本轮服务文件，视频模板及其他服务保持生产版本；另从冻结源码只叠加本轮手动确认UI后构建Next产物，禁止部署带旧自动识别UI的中间镜像。

新镜像显式设置 `STUDIO_ASR_ENGINE=nano` 与 `STUDIO_ASR_DIR=/app/.runtime/asr-nano`；Compose 沿用镜像中的值，不能设置旧的 ASR 目录覆盖它。不同引擎版本生成独立缓存摘要，既有手工字幕/草稿不强制覆盖。安装失败、对齐失败不自动切收费接口或旧模型。主动生成原声字幕时使用新模型；已填入旧字幕的原片须在界面明确重新识别。

推理依赖固定为 `numpy==2.2.6`、`onnxruntime==1.23.2`、`kaldi-native-fbank==1.22.3`，由安装入口准备，业务请求不安装依赖。内部脚本 `scripts/asr-nano-inference.py` 仅接受本地16kHz、单声道、16位PCM WAV，最长600秒；服务端负责提取该格式。Nano子进程最多840秒，整个媒体任务仍受服务端15分钟限制。单段SRT不得重叠或超过31秒；尾部至多100毫秒的容差裁回原片边界，其他越界直接失败，最终最多600条字幕。原文只进入所属workspace的临时文件和结果，不写入进程日志；输出权限0600。失败保留原项目字幕，不能把空结果、截断文本或虚构时间当作补救。

共用下载器 `install(directory, files=FILES)` 只增加管理员传入固定资产清单的能力；不传清单时仍安装原SenseVoice资产，既有SHA256校验、临时下载文件和原子替换行为不变。离线算法检查可使用已安装运行时的 Python 执行 `scripts/asr-nano.test.py`，不下载模型、不调用网络；实际模型和资源验收仍须单独执行。

## 验收与切换

先在独立 loopback 容器、临时测试账号/目录验证；保留真实短片、连续讲话长片、静音、队列取消、运行取消、账号隔离、峰值内存/回收/OOM以及原生和混合实际MP4证据。长片通过范围按实际样本记录，不以短片推断10分钟上限。浏览器权限受限时明确标注，禁止绕过。源码门禁和复核完成后检查正式站空闲；如仍有新素材/成片，先让用户下载并暂停，再切镜像。重启清空临时业务媒体；账号密码与独立会话挂载保留。回滚恢复上一镜像，不能恢复旧临时业务数据或覆盖账号配置。

实际验证结果和最终发布状态记录于 `docs/verification.md`，本说明不是上线已完成的证明。

正式容器的部署检查使用现有HTTP接口、Docker健康状态和只读文件检查。不要在同一业务data挂载上另起Node/tsx进程导入服务模块：临时模式的模块依赖可能初始化工作目录并清除前一进程的session目录，干扰主服务启动。模型就绪可读取镜像环境、对应ready.txt及现有服务接口；需要独立运行代码时使用隔离data目录。
