## 主流程与范围

用户上传房源照片，填写房源信息，为每个场景写解说和选择轻微运镜。React 页面使用 Remotion Player 预览；同一视频组件由本地 Node 服务渲染成 H.264 MP4。支持普通话单人解说、本地录音和背景音乐，默认竖屏 1080×1920、30fps，也支持横屏。数据、上传文件、语音和成片保存在本机；初版不接入付费模型、不做账号系统或在线部署。本轮按用户新增要求，增加本地照片数字人口播开场。演示照片明确标注为演示，用户可以替换。

## 结构与新增内容

- `src/pages/studio/`：唯一业务页面，聚合编辑器、场景列表、预览、API 和本地编辑状态。
- `src/video/`：前后端复用的视频模板、场景运镜与字幕。视频像素布局允许内联样式，动画由帧数确定，禁止用 CSS 动画驱动成片。
- `src/services/definition/project.ts`：Zod 运行时契约、TypeScript 类型、显式枚举，前后端共同使用。
- `server/`：本地 Express API、文件处理、语音生成和渲染任务。只监听 127.0.0.1，单任务渲染，并发提交返回 409，失败可见且可重试。重启后运行中的任务标为失败，不伪造完成。
- `public/demo/`：演示房源照片；`data/`：忽略提交的上传、任务、成片与草稿。
- 项目自带 Skills、启动命令、验收脚本和使用文档。无需数据库、云队列、外部 API 密钥。

## 关键行为

1. 图片经 Sharp 解码为 JPEG 后保存；只接受 JPEG/PNG/WebP，限制单文件 20MB、最多 20 场景。音频经元数据解析校验，限制 50MB、10分钟。
2. 服务端只接受本地 `/media/` 与 `/demo/` 资源路径，拒绝远程 URL、路径穿越和缺失资源，防止渲染器访问任意地址。
3. 逐场景使用 macOS `say` 生成中文语音，命令使用参数数组，无 shell 拼接。按真实音频时长延长场景，确保说完再切换；修改解说会清除对应旧配音。
4. 总帧数等于各场景帧数之和减去相邻转场重叠帧。字幕按解说标点及长度分句，在对应场景内展示；为估算字幕时间，不承诺逐字强制对齐。
5. 配音、音乐分轨，音乐低音量循环；预览和导出使用同一输入快照。渲染进度通过轮询真实任务状态显示，成片完成后提供播放与下载。
6. 草稿可保存到本机、加载，并导入导出 JSON。文件持久保存，草稿不嵌入大图。空态、上传中、失败、渲染中和不可操作状态必须可见。

## UI 与工程约定

独立项目没有既有业务模块，页面按 `pages/studio` 内聚。React＋TS＋Vite＋Tailwind v4；主色 #56BEB2、hover #16B799、页面 #FAFAFA，字号 28/20/18/16/14/12px，操作按钮与输入框 40px，表单间距24px，容器显式居中。视频画布是独立媒体坐标系，不套用网页字号。

例外：为保证独立项目可安装运行，不依赖科研工作台私有运行时；HTTP 在业务 API 边界用原生 fetch 与 Zod 校验，Lint 使用公开 TypeScript/React Hooks 规则。前端异步使用 Promise 链。超过6个原子类用 clsx 按语义分组，禁止 clsx 三目。视频动态 transform、视频画布布局、播放器比例采用必要内联样式。
