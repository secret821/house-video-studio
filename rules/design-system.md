# 编辑器视觉与交互

按用户2026-10-30明确要求，页面控件统一使用Ant Design，保留此前Sprig参考确定的暖色、柔和黏土触感和手机优先操作。主题由StudioProvider与 `--studio-*` token共同表达，不采用antd默认蓝色或改变现有布局。保持房源制作工具结构，不引入原站学生文案、插图或注册流程。顶部宣传区与无操作价值的页尾文案继续移除，实拍入口直接显示步骤和上传区，照片模式仅保留模式标题和实际处理状态。

- 编辑器主色 #b9503b、悬停 #963d2c、背景 #fff4df、面板 #fffcf5、文字 #38243b、辅助文字 #776577。鼠尾草绿 #e9efdf 与淡紫 #eee8f6 仅用于素材分组和步骤。输入圆角12px、面板24px；主按钮胶囊和轻微厚度，面板低强度阴影。视觉token仍从 `src/theme.css` 统一读取。
- 标题使用28/36、20/30、18/28px；正文14/24、辅助12/20px。手机输入16px避免聚焦自动放大；按钮至少44px、折叠设置行48px、表单间距24px。用户的移动操作要求优先于此前40px控件高度。
- 实拍页顺序仍为“上传素材 → 整理文案 → 封面与声音 → 预览与生成”。空项目仍显示已录口播、房屋视频/照片、房源文字三类输入。步骤使用吸顶页内定位和阅读位置反馈，不能以完成上传作为访问文案的门槛。
- 顶部直接显示“新建”和“保存草稿”；模式切换和会话控制放入更多菜单，支持外部点击与Escape关闭。窄屏空间不足时顶部操作整组换行，不能隐藏新建入口或横向溢出。照片模式共用顶部导航与触控尺度。桌面编辑区加固定预览，窄屏输入在前、预览在后，并由底部按钮直接定位。
- AI建议、逐段时间、封面参数、混音与详细上传规格默认折叠。无效的自定义封面会展开修正入口。额度确认、主动调用、证据核对和采纳约束不变。识别结果仍需确认再写入；本地格式示例不自动填写为真实资料。
- 素材顺序随页面滚动，手机不再使用内部小滚动列表。房屋素材通过独立手柄以Pointer Events拖拽排序；支持边缘滚动、落点提示、越界或Escape取消、方向键替代操作。只有落下时提交插入排序，素材对应的所有片段跟随移动且保留时间与字幕。人物开场仍固定在房屋素材之前。底部固定栏保留预览、生成、下载和上传取消，长操作允许换行。使用安全区padding和足够页面底部留白；手机输入聚焦时隐藏固定操作栏，避免遮挡输入。
- hover、focus、active、selected、disabled保持尺寸和占位稳定。保留键盘、可见焦点、标签、错误与禁用状态；遵守减少动态效果偏好。长文件名、中文按钮和说明不能撑出视口。
- 视频画布不受产品UI主题覆盖；播放器与实际导出继续共用原时间轴、封面、原声与素材。不能用网页截图代替MP4验收。
- 改动需检查桌面与移动窄屏、资源、浏览器日志、水合、横向溢出和固定栏遮挡。来源与截图保存在 `artifacts/ui-refresh-2026-10-30/`，真实验收见 `verification.md`。

## 2026-11-01 操作区与图标

按用户要求，界面图标统一为 Ant Design Icons；不使用 emoji 作为操作图标。试听分别使用播放、暂停、加载图标，并保留文字和可访问名称；折叠使用 antd 默认箭头。字幕生成、确认/移除采用独立 Flex 操作行，垂直居中、12px 间距并可换行；显示字幕选项独立一行，表单组间24px。上传音乐单独一行，音量建议和关闭为同一操作组。手机顶部操作可换行，页头随页面滚动，步骤导航固定于顶部，避免叠压；桌面/手机均提供底栏预览入口。暖色token、44px触控尺度和原有业务行为继续沿用。

## 组件库与工具样式的层级

根布局的 AntdRegistry 启用 layer；theme.css 在 Tailwind 导入前声明 `theme, base, antd, components, utilities` 顺序，让库样式高于基础 reset、低于显式布局工具类。避免用 !important 逐个修补被库 reset 覆盖的 margin。音乐搜索组使用 Flex 的12px gap，搜索状态与结果列表分开；搜索成功自动展开并显示数量，中文常用词显式映射英文标签，未知词保留原文。维护时须检查桌面和375px窄屏的实际计算样式、下拉框与固定底栏。
