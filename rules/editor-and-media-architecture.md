# 编辑器与媒体工具架构

本规则把只读 `image-forge-AI/rules` 的 board、canvas、tool 和 training 页规则中可迁移的职责、交互、状态与验收方法，改成当前房源视频工作室的真实结构。本项目没有科研画板、模型训练、工具注册表、画布节点或坐标锚点；不要引入其接口、权限或私有组件。

## 编辑器职责

- `src/features/studio/photo/` 与 `video/` 各自拥有页面配置和交互；`media/` 只放两种模式已共同使用的文件上传、素材排序与音乐选择；`shell/` 负责模式导航、主题与会话展示。
- `src/services/definition/project.ts`、`video-edit.ts`、`subtitles.ts` 等共享契约定义项目状态。前端只编辑当前账号/模式唯一草稿，服务端用 revision 防止旧页面覆盖新项目。
- 控件的点击、拖拽、键盘事件先进入 feature Hook，再调用业务 API 或更新当前编辑态；`src/share/ui` 只适配 Ant Design 行为，不持有房源、素材或任务状态。
- 上传只保存原片与受限元数据。字幕识别、智能清理、配音和生成成片须由用户主动触发；后台任务用服务端编号、账号 workspace、媒体单槽和取消保护，不能挂在 React 组件的存活时间上。

## 时间与画面

- `src/video/` 是预览、两种 MP4 路径与封面帧映射的共同来源。动画按帧数而非墙上时钟计算；视频画布内联样式仅为画幅、裁切、定位、逐帧动画和必要原生媒体适配。
- 原片时间、片段时间、输出帧和字幕区间必须明确转换。剪辑不能为转场重叠或删去原声讲解；静音封面不显示讲话字幕。单个素材替换/移除后，迟到任务结果不能写回新素材。
- 素材排序保留业务 id 和键盘操作；拖动结束后再保存新的顺序。画布预览、封面 PNG、播放器 poster 和导出 MP4 应基于同一模板配置，不以 DOM 截图代替媒体渲染验收。
- `videoTemplate` 只控制片内文字与片尾，旧草稿缺失时为经典；`coverTemplate` 与 `coverStyle` 组成四种封面样式，`coverSource` 独立决定口播或房屋素材首帧。新草稿默认经典新版与房屋来源，旧草稿缺独立封面字段时沿用旧模板表现。任一项切换都保留素材、房源文字、原声、字幕和时间；预览与导出按当前封面配置渲染，旧成片仍可单独下载。

## 工具和异步动作

新增媒体能力时定义输入素材、输出文件/状态、失败与取消语义、workspace 归属、大小/时长预算、并发槽、缓存身份和清理保护。对用户可见的上传、识别、清理、配音、预览、生成/下载动作，均提供待处理、执行中、成功和失败状态；不伪造完成或静默回退。用户主动选择在线音乐或 AI 文案，试听不等于选曲，模型建议不经确认不能覆盖房源事实。

## 验收

检查桌面和窄屏的点击、拖拽、键盘与取消；页面刷新和服务重启后的草稿/任务恢复；多账号 workspace 隔离；素材替换与迟到结果；预览与经典/杂志两套实际 MP4 的画面、编码、时长、原声和字幕。改动构建包、模板或依赖时同步 Docker 白名单与部署说明；只有用户明确授权才发布公网。
